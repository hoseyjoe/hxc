# ---------------------------------------------------------------------------------------------------------------
# System.IntPtr and UIntPtr are CLR primitives (native int, native unsigned int: ELEMENT_TYPE_I/U in signatures,
# as Roslyn writes fields, locals, returns and type arguments), and their methods are called on the value's
# address, as on any struct: a local's, a field's, or, for a call's result, a temporary's (Roslyn: `call native int
# P::handle(int32); stloc.s t; ldloca.s t; call instance int64 [System.Runtime]System.IntPtr::ToInt64()`). `new
# IntPtr(n)` is `newobj instance void System.IntPtr::.ctor(int32)` (int64 for an Int64), boxing is `box
# System.IntPtr`, a Dynamic back is `unbox.any`. == compares the native ints (gencs calls Equals: the same).
# Today: every `new IntPtr(..)` and every call on a call's result is refused ("conversions between value types
# are not supported yet", P.hx:4, 5, 9, 11, 17, 25, 27): the .NET type hxc binds the member on is
# valuetype System.IntPtr, the value's type native int.

# 2. CompilerGeneratedAttribute on a @:property var's backing field and accessors
# ---------------------------------------------------------------------------------------------------------------
# Roslyn writes [CompilerGenerated] (ctor sig 20-00-01, blob 01-00-00-00, no DebuggerBrowsable, in Release and
# Debug builds alike) on an auto-property's backing field and on both accessors, static or instance, in a
# @:nativeGen, a hxgen and a generic class, and nowhere else (not on the Property row, not on gen_prop's
# properties). Reflection sees them (IsDefined), and so does Newtonsoft.Json once non-public members are searched
# (it then skips the backing field only when it carries the attribute); System.Text.Json does not.
# Today: each of the three lines ends after the colon (no member carries the attribute).
--- property-var-compiler-generated @gencs
@:nativeGen
class Model {
	@:property public var name:String = "";
	@:property public static var total:Int = 3;
	public function new() {}
}
class Box<T> {
	@:property public var item:T;
	@:property public static var made:Int;
	public function new(t:T) item = t;
}
class Plain {
	@:property public var x:Float = 1.5;
	public function new() {}
}
class P {
	static function main() {
		var m = new Model();
		var b = new Box<String>("s");
		var p = new Plain();
		var CG = cs.Lib.toNativeType(cs.system.runtime.compilerservices.CompilerGeneratedAttribute);
		for (t in [cs.Lib.toNativeType(Model), cs.Lib.getNativeType(b).GetGenericTypeDefinition(), cs.Lib.toNativeType(Plain)]) {
			var all:cs.system.reflection.BindingFlags = new cs.Flags(cs.system.reflection.BindingFlags.Public) | cs.system.reflection.BindingFlags.NonPublic | cs.system.reflection.BindingFlags.Instance | cs.system.reflection.BindingFlags.Static | cs.system.reflection.BindingFlags.DeclaredOnly;
			var out = [];
			for (f in t.GetFields(all)) if (f.IsDefined(CG, false)) out.push("field " + f.Name);
			for (mm in t.GetMethods(all)) if (mm.IsDefined(CG, false)) out.push("method " + mm.Name);
			for (pp in t.GetProperties(all)) if (pp.IsDefined(CG, false)) out.push("property " + pp.Name);
			out.sort(Reflect.compare);
			Sys.println(t.Name + ": " + out.join(", "));
		}
	}
}

# 3. Ruling Z: a null argument, by C#'s betterness
# ---------------------------------------------------------------------------------------------------------------
# gencs writes a null into a reference-typed parameter as the literal `null`, so C# picks among the applicable
# overloads by betterness: at a null position T1 is the better parameter type when T1 converts implicitly to T2
# and T2 does not to T1; an overload better than every other one binds. S2(string)/S2(object): string
# (declared String or Dynamic alike); H(NBase)/H(NDerived)/H(object): NDerived; I(IDisposable)/I(object):
# IDisposable; T2(string,string)/T2(object,object) with two nulls: both strings; U(string,int)/U(object,int) with
# (null, 5): the typed position is the same type in both; X(string,string)/X(Thing,object): string and Thing are
# neither better at the first null, string is at the second, so X(string,string) is better; Q(string)/Q(object,
# int x = 0): only the given argument counts; a constructor alike. ByVal's N(null), P(null) and a padded O(1)
# (ruling X's three refused cases) bind as C# does: N(Thing), P(params object[]) with a null array, O(int,Thing).
# Today: all 12 are refused ("more than one .NET overload of ValLib.ByNull.S2 accepts (string) (C# converts an
# integer constant or null argument by its value; declare the parameter's exact type, or use @:overload)", etc.).
# This case replaces netlib-extern-null-to-class-or-object-refused, netlib-extern-null-to-params-or-object-refused
# and netlib-extern-padded-optional-null-refused.
